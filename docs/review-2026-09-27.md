## 2. The deck claims three things the code does not do

These matter more than a typo. The repository is public, the deck cites it, and a judge can
check all three in under a minute. The whole product argument is that unverifiable claims are
what this system exists to catch — so the deck cannot make one.

### 2.1 Six generation parameters, or four

The deck says *"Six generation parameters i.e. audience, tone, language, detail, objective,
style"*. `packages/shared/src/config.ts` defines four:

```ts
export const Config = z.object({
  audience: z.string().min(2).max(80),
  tone:     z.enum(['formal', 'neutral', 'conversational']),
  detail:   z.enum(['brief', 'medium', 'detailed']),
  language: z.enum(['en', 'hi']),
});
```

The problem statement does name six — *"target audience, tone, language, level of detail,
communication objective and content style"* — so the gap is real and worth closing. Two
routes, and either is fine as long as the deck matches:

- **D adds them**, roughly `objective: z.enum(['inform','warn','instruct','persuade','summarise'])`
  and `style: z.enum(['neutral','narrative','bulleted','technical'])`, plus one line in
  `buildPrompt()`. This is a `packages/shared` change, so it needs agreement first.
- **A changes the deck to four** and removes the two words.

### 2.2 Seven artefact types, or five

The deck says *"One source, seven artefact types … all generated together"*.
`packages/shared/src/formats.ts` enumerates five:

```ts
export const FormatId = z.enum([
  'advisory', 'executive_summary', 'linkedin_post', 'x_thread', 'video_package',
]);
```

Presentation and infographic are specified in the SRS but are not in the registry and are not
built. The honest line is **"five artefact types today, seven specified"**.

Slide 2 also disagrees with itself: the pipeline strip says *5 formats*, The Resolution says
*seven*, and *"One index, not five prompts"* says five again. Settling on **five** everywhere
fixes the claim and the inconsistency in one edit.

### 2.3 The cloud provider is Groq, not Gemini

Slide 3's diagram reads *CLOUD, GEMINI*. The code uses Groq:

```ts
// packages/ai/src/adapters.ts
import Groq from 'groq-sdk';
export class GroqAdapter implements LLMAdapter { … }
export const cloud = new GroqAdapter();
```

The deck must name what actually runs, with the exact model id from D. Guide A's rule is to
name the model and never write "our AI" where a model name is true.

**Related repo bug:** `.env.example` still reads `GEMINI_API_KEY=` and
`CLOUD_MODEL=gemini-flash-latest`. Anyone setting up from a clean clone configures the wrong
provider. Owner: D.
