F2

Read it top to bottom; that is one request. The client holds five screens and talks to the gateway over REST, then keeps a WebSocket open for progress frames. The gateway writes the source, spans and canonical object to PostgreSQL, enqueues one job per selected format on Redis, and answers in milliseconds so the cards paint immediately. It does no generation itself. The worker tier is the point of the figure. It is the only tier that can reach a provider, and the classification check runs inside it before an adapter is chosen. Public and internal go to the cloud model, internal with identifiers masked first; restricted goes to the on-device model and nowhere else; if neither is reachable the cached pack serves a degraded result rather than an error page. The engine band is the same pipeline as F7, compressed: extract once per source, route, generate per format, verify in code, repair at most once. The dashed lines are the worker writing back — artefacts, claims and audit rows to PostgreSQL, and progress events to a Redis stream that the gateway reads and forwards to the browser.
